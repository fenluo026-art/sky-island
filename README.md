# Sky Island / 天穹之境

这是重做后的干净 Godot 4.4.1 手机工程。

## 当前架构

- 世界逻辑面积：80,000 km²
- 程序化生成，不把 80,000 km² 全部实体资源塞进 APK
- 地表 + -1 + -2 + -3 + -4 多层架构
- -1：生活/交通
- -2：军事、大型机库、东西向贯穿通道
- -3：工业/仓储/设备
- -4：能源/控制/悬浮系统
- 预留 Chunk / LOD 扩展位置
- 手机操作：拖动旋转、滚轮/双指逻辑缩放
- 区域按钮可快速聚焦
- 一加 13 / 24GB RAM 作为目标测试设备

## Android 覆盖安装

固定 application id：

com.fenluo.skyisland

版本号必须递增：

1.0.0 -> 1.0.1 -> 1.0.2 ...

**最重要：所有后续 Release APK 必须使用同一份签名密钥。**

本工程的 GitHub Actions 预留了稳定签名流程。个人仓库请不要把 keystore 密码公开到仓库正文。

如果你已经安装了一个不同 application id 或不同签名的旧 APK，它不能被任何新工程强制覆盖；第一次从旧工程迁移到本工程时可能需要卸载一次。完成迁移后，后续版本按上述规则覆盖安装。

## 目标

这一版不是假装已经塞进一个完整的 80,000 km² 美术世界，而是先把底层架构做干净。
后续所有大型地形、建筑、城市、生态、车辆、地下设施都应该接入 Chunk/LOD 系统，而不是把全部资源一次性加载。
